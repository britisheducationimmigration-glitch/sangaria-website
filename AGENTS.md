# AGENTS.md

Website for British Education and Immigration (visa & IELTS/PTE consultancy, Sangaria, Rajasthan). **Continue from [PLAN.md](./PLAN.md)** — milestone 1 (public site) is done; next is the data model, then the admin panel.

## Architecture
- TanStack Start + React 19, Tailwind v4 (theme tokens in `src/styles.css` `@theme`: `forest-*`, `coral-*`, `cream`, `sand`; fonts Bricolage Grotesque / Figtree / JetBrains Mono).
- `src/routes/` file-based routes. `__root.tsx` renders header/footer/WhatsApp button in the shell. `routeTree.gen.ts` is generated by the build.
- `src/data/site.ts` business info + nav. `src/data/fixtures.ts` ALL stub content (countries, visas, posts, testimonials, approvals, coaching, FAQs) — swap for DB queries later, keeping the same types.
- `src/data/eligibility-rules.ts` the editable rules object; `src/lib/eligibility.ts` is the pure scoring engine (score = earned/max % over factors relevant to the goal; a country matches if score ≥ `minScore[goal]` and every `minFactor` is met). The admin rules editor should edit this shape, not code.
- `src/components/EnquiryForm.tsx` the only form. Netlify Forms, name `enquiry`, AJAX POST to `/__forms.html`. **Field names must stay in sync with `public/__forms.html`.** Hidden `source` (page) and `summary` (e.g. eligibility result) fields.

## Conventions
- Images live in `public/img/` and are always referenced through `img()` in `src/lib/utils.ts` (Netlify Image CDN).
- Design language: dark forest-green sections with `bg-grain`, coral accents, hard offset shadows (`shadow-[4px_4px_0_0]`), ticket/boarding-pass and passport-stamp motifs.
- No public user login — by owner's request. Login is only for the future admin area.
- Persistence: Netlify Database (Drizzle) for records; Netlify Blobs for uploaded images.
